# vizualizador-de-perfil-github
Visualizador de Perfil do GitHub desenvolvido com HTML, CSS e JavaScript. O projeto utiliza a API do GitHub para buscar usuários e exibir informações como foto de perfil, nome, bio, seguidores, seguindo e repositórios recentes. Projeto responsivo criado para praticar consumo de APIs, async/await e manipulação do DOM.
